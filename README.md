# Construction company website

Individualių namų statybos įmonės svetainė (LT / RU / EN).

- `index.html` – pagrindinis puslapis su kainų skaičiuokle
- `projektai.html` – užbaigtų objektų puslapis
- `policy.html`, `consent.html` – privatumo politika ir sutikimas (šablonai)
- `img/` – laikinos iliustracijos, keičiamos tikromis nuotraukomis

Svetainė diegiama į GitHub Pages automatiškai po kiekvieno `push` į `main` (`.github/workflows/deploy.yml`).

**Būsena:** prototipas. Kainos, atsiliepimai ir kontaktai yra demonstraciniai. `robots.txt` draudžia indeksavimą, kol svetainė nepatvirtinta.
